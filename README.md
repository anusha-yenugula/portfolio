# Anusha Yenugula — Portfolio

Static site. No build step.

## Pages
- `index.html` — Home / work
- `about.html` — About
- `identity-project.html`, `individual-pensions.html`, `native-member-app.html` — Case studies

## Deploy
**Vercel:** import this repo at vercel.com/new. Framework preset: Other. No build command, output directory `./`.

**GitHub Pages:** Settings → Pages → Deploy from branch → `main` / root.

## Local preview
```
npx serve .
```
